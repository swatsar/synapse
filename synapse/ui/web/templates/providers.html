Модели, которыми пользуется Synapse

Synapse не привязан к одной нейросети. Здесь вы подключаете провайдеров — Anthropic, OpenAI, Ollama или любой совместимый API — и задаёте их приоритет. Дальше OmniRouter сам решает, какая модель лучше подходит под конкретную задачу: код, сложные рассуждения, работа в браузере или приватная локальная обработка.

Профиль провайдера хранит адрес API и ссылку на секрет, но никогда не сам ключ. Поэтому ключи можно держать в переменных окружения или в зашифрованном хранилище.

Профиль не переключает текущий runtime автоматически: после смены окружения перезапустите Synapse.

Добавить провайдера

Заполните профиль один раз. Если не хотите хранить ключ в Synapse, используйте ссылку на секрет — например, secret://env/OPENAI_API_KEY. Перед этим создайте переменную окружения и перезапустите сервис.

Если при сохранении ключа появляется ошибка хранилища, значит на сервере не задан SYNAPSE_SECRET_KEY. Это не блокирует работу: выберите «Ссылка на секрет», задайте переменную окружения с ключом и перезапустите Synapse.

Подключённые провайдеры

Карточки упорядочены по приоритету. Проверка соединения обращается к реальному API; если провайдер требует ключ, которого нет в окружении, вы увидите честную ошибку.
